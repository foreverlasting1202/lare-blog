Noto Sans CJK SC, Regular and Bold, distributed under OFL.txt.

The reference blog uses Noto Sans CJK SC subsets. These local WOFF2 files
retain that typeface and extend coverage for the LARE article's Chinese text.
They contain the reference subset's glyphs plus the bilingual article/interface
characters, subset from the official Noto sources with fontTools 4.68.0:

https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf

Font copyright and naming metadata are preserved in the WOFF2 files.
The static website needs no font-subsetting tools or remote font service.
